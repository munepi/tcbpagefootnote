\section{Introduction}

\pkg{tcolorbox} typesets the content of a box like a \texttt{minipage}:
a \cs{footnote} inside the box is numbered with the \texttt{mpfootnote}
counter (as a, b, c) and its text is put at the bottom of the box.
This is often what you want for a box that stands apart from the text,
but not for a box that is part of the running text, such as a note or
a definition in a book: there, the footnotes should share the numbering
of the body text and go to the bottom of the page.

The \pkg{tcbpagefootnote} package adds the \pkg{tcolorbox} key
\key{page footnote} for this.  The two boxes below differ only in this
key.

\begin{tcolorbox}[title=An ordinary box]
A footnote in an ordinary box\footnote{This footnote is put at the
  bottom of the box.} is a footnote of the box.
\end{tcolorbox}

\begin{tcolorbox}[title=A box with \key{page footnote}, page footnote]
A footnote in a box with \key{page footnote}\footnote{This footnote is
  put at the bottom of the page.} is a footnote of the page, numbered
along with the footnotes of the body text.
\end{tcolorbox}

\paragraph{Supported formats/engines}
pdf\LaTeX, Xe\LaTeX, Lua\LaTeX{} (with or without Lua\TeX-ja),
p\LaTeX{} and up\LaTeX{} (with dvipdfmx); horizontal (yoko) and
vertical (tate) writing.  The package requires \pkg{tcolorbox} and
loads its \texttt{hooks} library.  With Lua\LaTeX, it also loads
\texttt{tcbpagefootnote.lua}.

\section{Usage}

\begin{verbatim}
\usepackage{tcbpagefootnote}

\begin{tcolorbox}[title=Note, page footnote]
  Text\footnote{A page footnote.}.
\end{tcolorbox}

\newtcolorbox{note}[1][]{colback=blue!5, page footnote, #1}
\tcbset{page footnote}  % for every box
\end{verbatim}

\noindent
The key acts on the footnotes in the title, the upper part and the lower
part of the box:
\begin{itemize}
\item the marks are made with the \texttt{footnote} counter and
  \cs{thefootnote}, as in the body text;
\item the texts are collected while the box is typeset and are put into
  the ordinary footnote insertion right after the box, so that they go
  to the bottom of the page where the box is.  If the box does not fit
  on the current page and moves to the next one, its footnotes move
  with it.
\end{itemize}
\cs{footnote}\texttt{[\meta{number}]}, \cs{footnotemark} with
\cs{footnotetext}, \cs{tcbox}, and boxes with \key{page footnote} inside
each other work as usual.  An ordinary box inside a box with
\key{page footnote} keeps its own footnotes.  With \pkg{hyperref}, each
footnote mark links to its own footnote text.

\paragraph{Breakable boxes}
A \key{breakable} box that is broken across pages puts each footnote
text on the page of its mark, like the body text does, and each part of
the box leaves room for its footnotes.  This is done in one run, in a
way that depends on the engine.
\begin{itemize}
\item With Lua\LaTeX, the footnote texts are real insertions at their
  marks.  When \pkg{tcolorbox} splits the content of the box, each part
  keeps the insertions of its marks, and \pkg{tcbpagefootnote} moves
  them out of the part to its page.  The content is split as if each
  line with a footnote mark were as much higher as its footnote text
  needs at the bottom of the page.
\item With the other engines, each footnote text is typeset at its mark
  and kept in a box, and a \TeX{} mark (\cs{marks}) at the footnote
  mark tells which part the footnote belongs to.  The content is split
  again, from a copy, until the part and its footnotes fit.
\end{itemize}
See also Section~\ref{sec:limitations}.

\paragraph{Breakable boxes inside breakable boxes}
\pkg{tcolorbox} does not break a box inside another box.  With the
\pkg{tcbnestbreak} package it does: a \key{breakable} box inside a
\key{breakable} box is broken together with the outer box.  If both
boxes have \key{page footnote}, the footnotes of the inner box are put
on the pages of their marks as well.

\paragraph{Tagged PDF}
With the new footnote code of \LaTeX{} (loaded, e.g., by
\verb|\DocumentMetadata{tagging=on}|), the footnote text is typeset
where its mark is, as in a \texttt{minipage}, and the typeset text is
put into the footnote insertion after the box.  In the structure tree,
the footnote (\texttt{FENote}) then directly follows its mark
(\texttt{Lbl}), as for a footnote in the body text.  The text is set in
the \cs{columnwidth} outside the box and in the normal color, not in the
text color of the box.

\paragraph{Vertical writing}
\key{page footnote} also works in tate, with the tate classes of
p\LaTeX{} and up\LaTeX{} (e.g.\ \texttt{tarticle} and
\texttt{utarticle}) and of Lua\TeX-ja (e.g.\ \texttt{ltjtarticle}).  With p\LaTeX{}
and up\LaTeX, load the \pkg{pxpgftate} package as well: without it,
TikZ/PGF, and so \pkg{tcolorbox}, draws the boxes sideways in tate.
\pkg{tcbpagefootnote} does not load it itself.
\begin{verbatim}
\documentclass[dvipdfmx]{tarticle}
\usepackage{tcbpagefootnote}
\usepackage{pxpgftate}
\end{verbatim}

\section{Errors and warnings}

\begin{description}
\item[\texttt{The key 'page footnote' cannot be used with 'float'.}]
  A floating box (\key{float}) is not followed by the code that puts the
  footnotes.
\item[\texttt{The 'after' code of this box no longer flushes the page
  footnotes.}] The footnotes are put by the \key{after pre} code of the
  \texttt{hooks} library.  Keys that set the whole \texttt{after} code
  (such as \key{after}, \key{after skip} and \key{nobeforeafter}) remove it
  when they come after \key{page footnote}: give them before it, e.g.\
  \verb|[after skip=1pt, page footnote]|.
\item[\texttt{The tcolorbox key 'page footnote' is already defined.}]
  Another package defines a key of the same name; \pkg{tcbpagefootnote}
  does not redefine it.
\item[\texttt{This box is broken across pages.} (warning)] Only in
  \texttt{multicols} or inside another box; see below.
\end{description}

\section{Limitations}
\label{sec:limitations}

\begin{itemize}
\item In a \texttt{multicols} environment, where the footnotes are
  below all the columns, and inside another box such as a
  \texttt{minipage}, a \key{breakable} box that is broken puts the
  footnote texts of all its parts where the box ends.  The package
  issues a warning for such a box when it has footnotes.
\item With an engine other than Lua\TeX, a footnote inside a box of the
  content of a broken box (e.g.\ a \cs{footnotetext} in a
  \texttt{tabular}) can be put on the page after that of its mark:
  \TeX{} does not see the mark of such a footnote when the content is
  split.  Also, the footnote text is typeset through
  \cs{@footnotetext} with \cs{insert} redefined; a class or package
  whose \cs{@footnotetext} does not use \cs{insert}\cs{footins} is not
  supported there.
\item With Lua\LaTeX, the part of a broken box on a page that has no
  footnote before the box can be up to \cs{skip}\cs{footins} (the
  space above the footnotes) shorter than without \key{page footnote},
  when the part has no footnote but the rest of the box has one.
\item \key{page footnote} cannot be used with \key{float}.
\item With p\LaTeX{} and up\LaTeX{} in tate, a \cs{footnotetext} in
  vertical mode (e.g.\ right after a box) does not work with the new
  footnote code of \LaTeX{} (\cs{DocumentMetadata}), with or without
  this package.  Put it in a paragraph.
\end{itemize}

\section{Tests}

\verb|make test| compiles the test files with pdf\LaTeX, Xe\LaTeX,
Lua\LaTeX, p\LaTeX{} and up\LaTeX{} (+ dvipdfmx) and checks the log.
For every footnote, \texttt{test-common.tex} records in the
\texttt{.aux} file at shipout the page and the mark of both the footnote
mark and the footnote text, and whether the text is set in the full
\cs{columnwidth} of the page (a page footnote) or in a box; when the
\texttt{.aux} file is read back at \verb|\end{document}|, it checks
that every text is typeset exactly once, with its own mark, on the
expected page (\texttt{TPF-RESULT OK}).

\section{History}

\begin{description}
\item[v1.4 (2026/11/22)] A \key{breakable} box that is broken across
  pages puts each footnote text on the page of its mark: with
  Lua\LaTeX{} through the new file \texttt{tcbpagefootnote.lua}, with
  the other engines through \cs{marks}.  With the
  \pkg{tcbnestbreak} package, this also holds for a breakable box with
  \key{page footnote} inside such a box.
\item[v1.3 (2026/11/17)] Vertical writing: \key{page footnote} is
  tested in tate with p\LaTeX{}, up\LaTeX{} (with \pkg{pxpgftate}) and
  Lua\TeX-ja.  The code of the package is unchanged.
\item[v1.2 (2026/11/16)] Tagged PDF: with the new footnote code of
  \LaTeX, the footnote text is typeset at its mark and output after the
  box, so that its \texttt{FENote} follows the \texttt{Lbl} of its mark
  (\href{https://github.com/latex3/tagging-project/issues/1709}{latex3/tagging-project\#1709}).
\item[v1.1 (2026/11/14)] With \pkg{hyperref}, a \cs{footnotetext}
  after a box for a \cs{footnotemark} in the box gets the anchor of its
  mark: the mark and the anchor of the last footnote are restored after
  the footnotes of the box are put.
\item[v1.0 (2026/10/25)] First public release.
\end{description}
